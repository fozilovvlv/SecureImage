# SecureImage (Дипломная работа)

## «Разработка мобильного приложения для защиты персональных данных в изображениях посредством удаления EXIF-метаданных и нанесения динамических водяных знаков»

### 1. Назначение
Приложение **SecureImage** предназначено для превентивной защиты конфиденциальных данных и цифровых копий документов (паспортов, ID-карт, водительских удостоверений) перед их передачей через мессенджеры (Telegram, WhatsApp), электронную почту и веб-сервисы.

### 2. Решаемые проблемы
1. **Утечка персональной информации через EXIF**:
   - Точные GPS координаты (географическая привязка к дому, работе);
   - Производитель и точная модель устройства;
   - Дата, время и уникальные серийные номера камеры;
   - Программное обеспечение устройства.
2. **Несанкционированное повторное использование сканов документов**:
   - Оформление микрозаймов и кредитов третьими лицами;
   - Регистрация сим-карт и фейковых аккаунтов.

### 3. Технологический стек
- **Flutter & Dart**: Кроссплатформенный фреймворк мобильной разработки;
- **Material 3**: Современная адаптивная дизайн-система Google;
- **image & path_provider**: Локальная обработка и безопасное сохранение;
- **shared_preferences**: Локальные настройки и история;
- **100% Offline Privacy**: Нулевая зависимость от внешних серверов.

### 4. Архитектура проекта
Чистая модульная архитектура (Clean Architecture):
```
lib/
├── core/                  # Темы, локализация, константы
│   ├── theme/
│   ├── localization/
│   └── constants/
├── features/              # Функциональные модули
│   ├── exif/              # Парсинг и бинарная очистка EXIF
│   ├── watermark/         # Движок динамического водяного знака
│   ├── home/              # Главный экран
│   ├── protection/        # Интерактивный экран защиты
│   ├── history/           # Локальная история операций
│   └── settings/          # Настройки и приватность
└── main.dart
```

### 5. Инструкция по сборке в Android Studio
1. Установите Flutter SDK (версия 3.19+ или новее).
2. Откройте папку проекта в Android Studio или VS Code.
3. Выполните установку зависимостей:
   ```bash
   flutter pub get
   ```
4. Запустите статический анализ:
   ```bash
   flutter analyze
   ```
5. Запустите автоматические тесты:
   ```bash
   flutter test
   ```
6. Соберите релизный Android APK:
   ```bash
   flutter build apk --release
   ```
Файл APK будет сгенерирован по пути:
`build/app/outputs/flutter-apk/app-release.apk`
